  CODE
  {

    BEGIN
    {
      Список "таблица плюс поле, несущее номер документа". Единственное место, где номера
      доработанных объектов заказчика вообще появляются, - и появляются они в ДАННЫХ, а не
      в коде: код уезжает в публичный репозиторий, данные остаются на контуре.

      Колонка "переходник заведён" заполняется не человеком, а сторожем, и смотреть на неё
      надо в первую очередь: номер таблицы в подписке на событие - константа времени
      компиляции, поэтому на каждую таблицу нужен свой маленький объект-переходник. Строка
      без него выглядит рабочей и молчит.
    }
    END.
  }
